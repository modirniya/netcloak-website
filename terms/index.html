2. SERVICE DESCRIPTION

2.1 What We Provide

NetCloak is a free VPN service for Android, using the WireGuard protocol. It provides an encrypted connection through servers we operate. It is supported by advertising, although how often an advertisement appears is a setting we control remotely and can set to zero.

2.2 Connection Modes

Sessions are bounded by time, not by a data allowance. Before connecting you pick a mode, which trades speed against how long the session lasts:

  • Marathon: 80 minutes at the base speed
  • Balanced: 40 minutes at twice the base speed — the default
  • Sprint: 20 minutes at four times the base speed

Watching a rewarded advertisement adds another block of your mode’s length to whatever time is left. Remaining time is capped at 180 minutes, so an extension may add less than a full block, or nothing at all, and the app will tell you when that happens.

The app warns you as a session runs low: our server marks it “low” between 5% and 15% of the window remaining and “critical” at 5% or less. Those warnings prompt you to extend; they do not end the session.

2.3 Fair Use

There is no data allowance to spend and none is shown in the app. Transfer volume is measured only against an anti-abuse ceiling of 10 GB per session, which exists so a single session cannot exhaust a shared server.

2.4 Ad-Supported Model

Extending a session may require watching a rewarded video advertisement served by Google AdMob. The reward is granted at Google’s own threshold for the advertisement. How often an advertisement is required is set remotely and can be zero, in which case extensions are granted without one.

2.5 Server Infrastructure

  • Servers are selected automatically by availability and capacity
  • Manual server selection is not offered
  • Server capacity is finite, and a connection attempt can be refused when a server is full
  • Service availability depends on that capacity

3. ACCOUNT & ACCESS

3.1 Anonymous Authentication

  • No registration, account, email address or password is required
  • Our own backend issues an access token, which the app stores in Android Keystore-backed encrypted storage
  • The identifier inside that token is anonymous and is not tied to your identity
  • There is no account recovery, because there is no account

3.2 Session Management

  • A session lasts for the length of the mode you chose, and our server decides when it expires
  • Sessions can be extended, subject to the 180-minute cap in §2.2
  • One session per user is active at a time
  • The app checks the remaining time about every 30 seconds, and disconnects roughly 30 seconds before expiry so you are not cut off mid-transfer
  • If the tunnel stops responding, the app ends the session and tells you, rather than continuing to show a connection that carries nothing

3.3 When We End a Session Early

Your session may be ended before its time is up if:

  • its time has run out
  • the tunnel has gone idle, with no WireGuard handshake for five minutes
  • the session was created but never connected within three minutes
  • you started a newer session, which supersedes the older one
  • the server is under capacity pressure and is reclaiming space
  • a peer has been left behind by a failure and is no longer attached to a live session

Reconnecting after any of these starts a new session.
